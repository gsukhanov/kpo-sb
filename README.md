# ДЗ4: Онлайн-магазин

В этой ветке находится реализация проекта онлайн-магазина, состоящая из 4,5 сервисов:
1. Payments service - отвечает за работу со счетами и балансом, и имеет следующий функционал:
   1. Создать счёт для данного пользователя
   2. Узнать баланс данного пользователя
   3. Пополнить баланс данного пользователя
   4. Списать деньги за оплату заказа со счёта данного пользователя
2. Orders service - отвечает за работу с заказами, и имеет следующий функционал:
   1. Посмотреть список заказов данного пользователя
   2. Узнать статус заказа с данным ID
   3. Создать заказ
3. API Gateway - отвечает за передачу сообщений между сервисами.
4 и 4,5. Фронэнды - их два, один формата "для пользователя", второй формата "для дебага". Фронтэнд для дебага отличается наличием лога и чуть большей функциональностью.

Требования идемпотентности операций пополнения и списания обеспечиваются двумя способами:
1. Со стороны payments service и orders service они обеспечиваются с помощью transactional inbox/outbox.
2. Со стороны Gateway они обеспечиваются уникальными ключами идемпотентности сообщения - таким образом повторный запрос с одинаковым ключом не выполняется, а запросы с разными ключами исполняются даже если они в остальном идентичны.

Весь функционал можно протестировать в двух фронтэндах.

# Инструкции по сборке и использованию

Перейдите к папке online-store соберите проект командой `docker compose up --build`, или же используя Docker Desktop.

Затем элементы проекта будут доступны по следующим адресам:
1. [frontend-user](http://localhost:3000)
2. [frontend-dev](http://localhost:3001)
3. [swagger](http://localhost:8080/swagger-ui/index.html#)

Базы данных payments-db по порту 5432:5432, orders-db по порту 5433:5432, логин и пароль к обеим - postgres.
